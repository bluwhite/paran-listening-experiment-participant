# 파란 청취 실험 도구 — 참가자용

GitHub Pages 배포용 참가자 패키지입니다.

## 포함 기능
- 참가자 번호 입력
- 실험 프로젝트 열기
- 음성 듣기와 응답
- 다시 듣기 / 이전 문제
- 자동 저장 / 이어서 하기
- 결과 JSON 저장

## 아이콘 자산
`assets/` 안의 아이콘 PNG와 favicon은 **투명 배경으로 다시 생성**했습니다.
모서리 알파값을 검사해 투명 처리를 확인했습니다.

## GitHub Pages
- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

배포 주소 예: `https://사용자명.github.io/paran-listening-experiment-participant/`
